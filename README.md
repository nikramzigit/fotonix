# FotoNix

Aplikasi Android native (Java + Canvas, tanpa WebView) untuk menyunting imej dengan pantas.

## Ciri
- Buka imej daripada galeri
- Conteng dengan 3 warna pen: merah, hitam, biru
- Putar 90°
- Pangkas (crop)
- Laras kecerahan
- Undur tindakan
- Butang **Ready**: simpan terus sebagai JPG ke `Pictures/FotoNix/` dengan nama `1_namafail.jpg`, `2_namafail.jpg`, dan seterusnya

## Cara Dapatkan APK (Tanpa Pasang Apa-apa)
1. Cipta repositori baharu di GitHub dan muat naik semua fail dalam folder ini.
2. Buka tab **Actions** — proses "Bina APK FotoNix" berjalan automatik (~5 minit).
3. Klik larian yang selesai, muat turun **FotoNix-apk** (zip), ekstrak, pasang `app-release.apk` pada telefon.

## Cara Bina Sendiri (Android Studio)
Buka folder ini dalam Android Studio → **Build > Build APK(s)**.
